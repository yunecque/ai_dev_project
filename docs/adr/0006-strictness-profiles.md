# ADR-0006: Профили строгости

- **Статус:** accepted
- **Дата:** 2026-09-21
- **Контекст:** Платформа должна обслуживать как security-критичные проекты, так и внутренние
  утилиты, без потери обязательных supply-chain контролей.
- **Решение:** два профиля — `strict` и `personal-project`. Профиль декларируется в
  `baseline.json`. Supply-chain controls (signing, SBOM, secret scanning) обязательны всегда.
- **Обоснование:** уменьшает трение для личных утилит, не ослабляя цепочку поставки.
- **Последствия:** policy-check читает профиль из baseline и меняет объём threat modeling/review.
- **Ссылки:** конституция §12; baseline.json.
